## Problem Statement
Most AI tools agree with you. 
MindForge challenges your thinking — detecting biases, scoring reasoning breadth, and generating counter-arguments to build better critical thinking.

## Features
- NLP-based perspective classification (12 categories)
- Cognitive bias detection (7 types)
- Diversity Score 0-100
- AI-generated counter-arguments
- Multi-user login system
- Per-user history tracking
- Weekly Thinking Report

## Tech Stack
- Python, FastAPI, SQLite
- NLP keyword classification
- JWT Authentication, bcrypt
- HTML, CSS, JavaScript


## ML Pipeline
1. Input → tokenise and normalise
2. Sentiment Analysis → emotional tone
3. Perspective Classification → TF-IDF scoring
4. Diversity Score → semantic group coverage
5. Bias Detection → phrase matching
6. Response Generation → LLM with debate memory
7. Data saved per user in SQLite
